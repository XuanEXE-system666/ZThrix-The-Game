# ZThrix-The-Game

A classic Tetris game made with TurboWarp. Features complete game logic, coin system, theme system, and more.

## How to Play

- Use the Left/Right arrow keys to move the piece
- Use the Spacebar to rotate the piece clockwise
- Use the Z key to rotate the piece counterclockwise
- Use the Up arrow key to hard drop the piece
- Use the Down arrow key to soft drop the piece
- Use the C key to hold the piece
- Game over when blocks stack to the top

## How to Run

### Play Online
You can run it directly in your browser via the following link:
- [Play Web Version](https://xuanexe-system666.github.io/ZThrix-The-Game/Web)

### Offline Run

#### From Source Code
Due to Git and GitHub reasons, the repository code requires a special method to work properly.
1. Download the `ZThrix` folder inside the `source code` folder of this repository.
2. Select all files in the folder and compress them into a `ZThrix.zip` file.
3. Rename the file (including the extension) to `ZThrix.sb3`.
4. Open [TurboWarp Online](https://turbowarp.org/editor) or download [TurboWarp Desktop](https://desktop.turbowarp.org/).
5. Load `ZThrix.sb3` from file in TurboWarp and click the green flag to start.

#### Play the Packaged Version
1. Go to the [Releases](https://github.com/XuanEXE-system666/ZThrix-The-Game/releases) page of this project.
2. Download the version for your operating system.
3. Extract the downloaded archive with an archiver tool.
4. Run the corresponding executable file.

## How to Package
If you wish to package this project, be sure to use [TurboWarp Packager](https://packager.turbowarp.org/).

### Packaging Steps
1. In the Packager, select the `ZThrix.sb3` file downloaded from this repository.
2. Scroll all the way down, click "Import Settings" and select the `Zthrix打包设置.json` file from the `other assets` folder.
3. Scroll back up and choose the desired format.
4. Click "Package" and download.
